# 追加実験 fixture

SFTPのファイル一覧、読取、プレビュー、転送と権限の確認に使うサンプルです。

## 共有ファイル

- [確認メモ](確認メモ.txt)
- [サンプル画像](サンプル画像.png)
- [2ページPDF](2ページPDF.pdf)
- [短い音声](短い音声.wav)
- [短い動画](短い動画.mp4)
- [読み取り専用テキスト](read-only/閲覧専用.txt)

| ファイル | 種類 | 確認すること |
|---|---|---|
| 確認メモ.txt | UTF-8 text | 日本語ファイル名と本文 |
| サンプル画像.png | PNG | 画像プレビュー |
| 2ページPDF.pdf | PDF | 2ページの読込 |
| 短い音声.wav | WAV | 音声ファイルの一覧/ダウンロード |
| 短い動画.mp4 | MP4 | 動画ファイルの一覧/ダウンロード |
| read-only/閲覧専用.txt | UTF-8 text | 読み取り専用権限 |
